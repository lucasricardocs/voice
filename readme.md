# 📖 Leitor de PDF com Voz Neural

App web gratuita para ler PDFs em voz alta com vozes neurais em **Português do Brasil**!

## ✨ Funcionalidades
- Upload de PDF
- Vozes masculinas e femininas (Edge TTS neural)
- Controle de velocidade de leitura
- Destaque de texto em tempo real
- Player de áudio embutido

## 🚀 Deploy no Streamlit Cloud
1. Faça fork deste repositório
2. Vá para [streamlit.io](https://streamlit.io/cloud)
3. Clique "New app" → selecione este repo → selecione `app.py`
4. Deploy automático! ✅

## 🛠️ Tecnologias
- Streamlit (frontend)
- Edge-TTS (voz neural gratuita)
- PyPDF2 (extração de texto)
